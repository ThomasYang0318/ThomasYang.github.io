# Thomas Yang — Personal Portfolio

A lightweight static portfolio built from my resume and project portfolio.

## Structure

- `index.html` — main portfolio page
- `projects/` — featured project detail pages
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and subtle scroll reveal
- `assets/images/` — project images
- `resume.pdf` — downloadable resume / portfolio PDF

## Preview locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

This repository contains the static portfolio source. If GitHub Pages is configured to deploy from `main` / root, the site will be published from this repository.
